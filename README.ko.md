## 개요

이 봇은 겐지 파쿠르 커뮤니티(디스코드) 운영을 돕기 위해 만들어졌습니다. 
파쿠르 코드 등록 및 조회, 클리어 기록 보드, 익명 메시지 기능을 제공합니다.

## 기능

### 코드 관리 (`/코드`)
- **추가** — 맵, 난이도, 체크포인트 수, 설명, 가이드 URL, 제작자 정보와 함께 파쿠르 코드 등록
- **수정** — 기존 코드 정보 업데이트
- **삭제** — 워크샵 코드 삭제
- **조회** — 맵, 난이도, 제작자 필터와 페이지네이션이 적용된 임베드 뷰로 코드 탐색

### 클리어 보드 (`/클리어`)
- **제출** — 파쿠르 코드 클리어 기록 제출
- **조회** — 페이지네이션이 적용된 클리어 보드 탐색
- **인증** — 클리어 기록 게시를 위한 역할 인증
- **취소** — 대기 중인 클리어 제출 취소
- 관리자용 제출 **승인 / 반려** (반려 시 모달로 사유 입력)

### 맵 관리 (`/맵`)
- **추가** — 지원 맵 목록에 새 맵 추가
- **수정** — 기존 맵 이름 변경
- **삭제** — 맵 목록에서 제거

### 익명 채팅 (`/익명`)
- **전송** — 입력 채널에 익명 메시지 전송
- **답장** — 메시지에 익명으로 답장
- **차단** — 익명 메시지 차단
- 관리자용 로그 뷰 (익명 메시지 작성자 추적)


## 설치 방법

### 요구 사항

- Python 3.12 이상
- 디스코드 봇 토큰 (디스코드 개발자 포털에서 생성)
- SQLite (별도 설치 불필요, 파이썬 내장 lib)

### 환경 변수

프로젝트 루트에 `.env` 파일을 생성하세요:

```env
SQLITE_DB_PATH=./db/data.db
DISCORD_BOT_TOKEN=디스코드_API_토큰_입력

DISCORD_SERVER_ID=서버_ID
LOG_CHANNEL_ID=로그_채널_ID
CLEAR_CHANNEL_ID=클리어_관리_채널_ID
CLEAR_PUB_CHANNEL_ID=클리어_공개_채널_ID
```

### 설치 및 실행

```bash
pip install -r requirements.txt
python main.py
```
